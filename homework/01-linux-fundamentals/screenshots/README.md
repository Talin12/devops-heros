# Screenshots — drop your images here

The README in the parent folder already contains **real terminal output** for every task,
so screenshots are an optional extra.

If you want to add them, save the files here using exactly these names:

- `01-links.png`
- `02-adduser-useradd.png`
- `03-journalctl.png`
- `04-cheatsheet.png`

Then open the parent `README.md`, scroll to the **Screenshots** section at the bottom,
and delete the `<!--` and `-->` lines so the images render.
